# Combat & XP Tracker

A RuneLite plugin that tracks average damage, max hit, and per-skill XP/hr in one sidebar panel, with an optional on-screen overlay.

## Features
- Average damage and max hit tracking
- Per-skill XP/hr with a rolling average window
- Right-click a skill to set a custom goal level (up to 99), with a progress bar and ETA
- Optional on-screen overlay mirroring the panel's key stats
